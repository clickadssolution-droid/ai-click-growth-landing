# Changelog

Los cambios se documentan desde la baseline formal V1. No existe un tag Git equivalente al momento de esta documentación.

## V1 — 2026-09-21

Baseline: `fcef26a445a4672ca1589170228e9a4ed4b06e72`

### IMPLEMENTADO

- Landing B2B para Auditoría Growth 360°.
- Home y `/gracias` con App Router.
- Sistema visual AI Click con Manrope, Inter y JetBrains Mono.
- Header, Footer, Hero, Oportunidades, alcance, ecosistema, experiencia aplicada, servicios, método, About, FAQ y CTA final.
- Perfil de Carlos Peña.
- Modal global responsive de dos pasos.
- Validación local y estados de error.
- Tracking interno desacoplado con seis eventos.
- Adaptadores de envío y WhatsApp.
- Motion CSS/SVG, scroll reveal y reduced motion.
- Assets de marca, favicon, icon y apple icon.
- Accesibilidad estructural del modal y controles.

### PENDIENTE

- GoHighLevel productivo.
- Tracking productivo y consentimiento.
- Número real de WhatsApp.
- Deployment en `https://iclicksolution.com`.
- Legal, privacidad y cookies.
- QA Playwright e Impeccable.
- Casos reales, métricas, testimonios y campañas.

- Envío simulado siempre exitoso.
