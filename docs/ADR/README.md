# Architecture Decision Records

Los ADR registran decisiones duraderas evidenciadas por la baseline `fcef26a`.

Estados usados:

- **ACEPTADA / IMPLEMENTADO:** decisión vigente en V1.
- **PENDIENTE:** requiere definición o ejecución futura.
- **DEUDA TÉCNICA:** consecuencia conocida por resolver.
- **DECISIÓN REEMPLAZADA:** decisión histórica sustituida.
